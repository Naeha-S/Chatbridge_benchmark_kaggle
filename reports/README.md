# Reports

- `generated/current/`: latest frozen-dataset QA, diversity, retrieval, release-audit, and reconciled outputs.
- `generated/review/`: human-review workbooks, completed review records, and reviewer packets.
- `generated/archive/`: prior integrity/repair reports and intermediate exports retained as immutable history.

The frozen dataset is `data/generated/continuitybench_v1.jsonl`. Generated artifacts are ignored by Git.
